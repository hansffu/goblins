* Live package grant proof of concept

The root flake provides the =goblins= package, default app, and development
shell for x86_64-linux, with nixpkgs and agent-sandbox.nix pinned in =flake.lock=.
From this worktree:

#+begin_src sh
nix build path:.#goblins
./result/bin/goblins serve
#+end_src

In a second terminal, run =./result/bin/goblins shell=. Inside Fish, request
=goblins request-package cowsay=, approve in the serve terminal, then run
=cowsay hello=. Arbitrary package attributes resolve from the pinned nixpkgs
revision; package grants do not restart the shell.

Alternatively, =nix run path:. -- serve= and =nix run path:. -- shell= run the
default app, and =nix develop path:.= puts =goblins= and build tools on PATH.
The explicit =path:.= also includes the currently uncommitted PoC files.
