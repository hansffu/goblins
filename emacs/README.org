#+title: Goblins for Emacs

A small Magit-style status buffer for the Goblins daemon. Requires Emacs 28.1+
and =magit-section= (included with Magit). Uses Emacs' built-in =jsonrpc= and
connects directly to the local host socket.

* Load and use

With your existing Emacs/Nix packages available, evaluate:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/goblins/emacs")
(require 'goblins)
#+end_src

Run =M-x goblins-status= and use =M-x goblins-start-server= if the server is not running.
You can invoke any Goblins command from any buffer; opening status first is
unnecessary. Server start/stop and refresh create or reuse their own status
buffer and leave the calling buffer's text and mode unchanged.
Startup runs asynchronously and connects the buffer automatically when ready.
Use =M-x goblins-stop-server= to stop the server and all its agents asynchronously;
the buffer reports when it has finished. These server commands have no default keybindings.
The server uses this buffer's state directory and starts from its
=default-directory=, just like running the CLI from that directory.
Set =goblins-executable= to the packaged binary's absolute path if =goblins=
is not on Emacs' =exec-path=.
Use =M-x goblins-run= (or =R= in status) to choose from your Nix-configured
goblins with completion and launch one in a new Ghostel buffer.
Pressing Enter without typing selects the default shown in the prompt.
Requires your installed Ghostel package with =ghostel-exec= and its native module; Goblins
never downloads the module. Rebuild the Goblins CLI from this checkout first,
since this uses the new =configurations= and =attach= commands.

The buffer updates automatically
and includes agents, pending requests, and collapsible recent request history.
Agents form a tree rooted at =host=, with children nested beneath their owners.
Branches start expanded; =TAB= collapses or expands children only. The overview
contains headings only, with no detail rows. =RET= opens a separate details view
for the selected sandbox or request. Sandbox details show session IDs and
startup/granted packages; request details show the reason and preview. Details
update live and stay tied to the selected identity. Use =b= or =q= to return to
the tree with selection and branch folds preserved. Request labels use the
sandbox's full tree path to distinguish matching names in different branches.

Stopped children remain under their parent while any session in that root branch
is active. Entire stopped or failed trees move intact to “Stopped agents”. That
section and recent request history start collapsed. Live updates preserve section
identity, selection and your folding choices.

| Key | Action |
|-----+--------|
| =R= | Choose and launch a goblin in Ghostel |
| =n= / =p= | Next / previous section |
| =TAB= | Expand / collapse tree children |
| =RET= | Open sandbox or request details |
| =t= | Open the selected sandbox's Ghostel terminal |
| =b= | Return from details to the tree |
| =a= | Accept the pending request at point |
| =d= | Deny the pending request at point |
| =g= or =r= | Reconnect and refresh |
| =q= | Return from details, or close the overview; agents keep running |

When Evil is enabled, the buffer starts in normal state with dedicated bindings:

| Evil key | Action |
|----------+--------|
| =R= | Choose and launch a goblin in Ghostel |
| =j= / =k= | Next / previous section |
| =h= / =l= | Collapse / expand section |
| =TAB= or =za= | Expand / collapse tree children |
| =RET= | Open sandbox or request details |
| =t= | Open the selected sandbox's Ghostel terminal |
| =b= | Return from details to the tree |
| =a= / =d= | Accept / deny the pending request at point |
| =gr= or =r= | Reconnect and refresh |
| =gg= / =G= | Beginning / end of buffer |
| =q= | Return from details, or close the overview |

Evil support works with either package load order and changes only this mode's
bindings. Evil is optional and is never installed or enabled globally by Goblins.

Outside status, =goblins-accept= and =goblins-deny= offer completion over pending
requests, showing the agent, package, reason and request ID. =goblins-visit=
offers your locally launched terminal buffers, including retained exited ones.
=goblins-quit= closes only the relevant status view, never the calling file or
terminal buffer. Commands use the current Goblins buffer's server when available,
otherwise =goblins-state-directory= or the default server directory.

Launches use the calling buffer's =default-directory=. Each launch gets a new
agent name from the daemon and a separate Ghostel buffer, even for the same
configuration. Status marks linked agents with =[t: terminal]=. Links use
the daemon instance and immutable session ID and live only in this Emacs
process. Closing/reopening status preserves them; killing the terminal buffer
removes the link. Terminal buffers stay available after process exit until you
close them. Agents started outside =goblins-run= have no terminal link, and
there is no adoption or terminal replay after a buffer is killed.
Goblins terminals keep their local launch directory in Emacs; namespace-local
shell directory reports are not interpreted as SSH hosts or host paths.

Acceptance starts provisioning; the request moves to recent history and its
state continues updating until ready or failed. Decisions always use the exact
displayed session/request/approval identity. If a selected request disappears or
moves to history, point returns to the top instead of selecting another request.
Disconnects, sequence gaps and errors disable decisions until =r= reconnects.
A timed-out decision is not automatically retried; refresh to inspect its outcome.

For a daemon launched with =--state-dir=, use =C-u M-x goblins-status= to select
that directory, or set =goblins-state-directory=. Otherwise the directory follows
the CLI's =$XDG_RUNTIME_DIR/goblins=, =/run/user/UID/goblins=, or
=/tmp/goblins-control-UID= fallback. Each directory gets its own status buffer.

This package starts a daemon only when you run =goblins-start-server=. It does not install
dependencies, run a package manager, or alter your Emacs configuration.
Nix-managed Emacs packages can be used
directly; there is no need to download another copy of Magit.

* Checks

Run with an Emacs that already has =magit-section= on its load path:

#+begin_src sh
emacs --batch -Q -L emacs --eval '(setq byte-compile-error-on-warn t)' \
  -f batch-byte-compile emacs/goblins.el
emacs --batch -Q -L emacs -l goblins-tests -f ert-run-tests-batch-and-exit
python3 -m unittest discover -s tests -p test_emacs.py
#+end_src

The Python integration tests exercise server start/stop/restart, real approvals,
and two simultaneous Ghostel launches with working-directory input and status
links. They skip when Emacs or =magit-section= is unavailable; the Ghostel test
also requires its installed native module. These commands use =-Q= and do not
load your init file or install Emacs packages.
